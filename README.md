# GitHub MCP Server Tutorial

このリポジトリは、GitHub MCP（Manage, Create, Publish）サーバーの機能を試すために作成されました。

## 目的

- GitHub APIを使った操作を学ぶ
- リポジトリの作成と管理
- ファイルの作成、更新、削除
- イシューとプルリクエストの管理
- コード検索と閲覧

## 機能一覧

1. リポジトリ操作
   - 検索
   - 作成
   - フォーク
   - クローン

2. ファイル管理
   - 作成
   - 更新
   - 削除
   - 内容の取得

3. コラボレーション
   - イシューの作成と管理
   - プルリクエストの作成と管理
   - コメントの追加

## 使用例

このリポジトリには、GitHub MCP Serverを使用した様々な操作の例が含まれています。
